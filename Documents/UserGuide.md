# Budget Planner

iOS-приложение для учета доходов и расходов.
С помощью приложения можно добавлять финансовые операции, редактировать и удалять их, просматривать текущий баланс и фильтровать список расходов.

## Вход в приложение

При запуске приложения отображается экран входа.

<p align="center">
  <img src="Screenshots/login.png" width="280">
</p>

Для перехода к списку операций:
- Нажмите **Log in**
- Откроется главный экран приложения
В текущей версии экран входа используется как демонстрационный сценарий и не выполняет настоящую авторизацию пользователя.

## Просмотр операций и баланса

После входа открывается список финансовых операций.

<p align="center">
  <img src="Screenshots/operation-list.png" width="280">
</p>

В верхней части экрана отображаются:
- **Balance** — текущий баланс
- **Expenses** — общая сумма расходов

В списке для каждой операции отображаются:
- название
- дата
- сумма

Доходы и расходы визуально различаются по цвету суммы.
Для просмотра подробной информации об операции нажмите на неё в списке.

<p align="center">
  <img src="Screenshots/operation-details.png" width="280">
</p>

## Фильтрация расходов

Чтобы отображать только расходы:
- На экране списка найдите переключатель **Show only expenses**
- Включите переключатель
- В списке останутся только операции типа **Expense**
Чтобы снова увидеть все операции, выключите переключатель.

<p align="center">
  <img src="Screenshots/filtered.png" width="280">
</p>

## Добавление операции

Чтобы добавить новую финансовую операцию:
- На экране списка нажмите кнопку "+"
- Выберите тип операции: **Income** или **Expense**
- Введите название операции
- Укажите сумму
- Выберите дату
- Нажмите **Add**

<p align="center">
  <img src="Screenshots/add-operation.png" width="280">
</p>

После сохранения новая операция появляется в списке.

## Редактирование операции

Чтобы изменить существующую операцию:
- Выберите операцию в списке
- На экране подробной информации нажмите **Edit**
- Измените необходимые данные
- Нажмите **Update**

<p align="center">
  <img src="Screenshots/edit-operation.png" width="280">
</p>

После сохранения обновленные данные отображаются в списке операций.

## Удаление операции

Чтобы удалить операцию:
- Откройте её из списка
- Нажмите **Delete**
- Операция будет удалена из списка

## Обработка ошибок

При добавлении или редактировании операции приложение проверяет введённые данные.
В частности, операция не должна иметь:
- пустое название
- некорректную сумму (меньшую или равную нулю)
При возникновении ошибки приложение отображает сообщение с описанием проблемы.

<p align="center">
  <img src="Screenshots/error.png" width="280">
</p>

После исправления данных операцию можно сохранить повторно.

Для запуска Budget Planner:
- Откройте проект в Xcode
- Выберите Simulator или подключенное устройство
- Запустите проект
