# Budget Planner

## Описание

Приложение для учета расходов и доходов пользователя. Позволяет отследить финансы за выбранный промежуток времени

Пользователь может быстро и удобно вносить изменения. Приложение подсчитывает доходы и расходы за выбранный промежуток времени. Фильтрует по категориям (доходы и расходы)

Данные пользователя сохраняются автоматически

## Функциональность

- Добавление операций (доходы и расходы)
- Редактирование
- Удаление
- Фильтрация операций по типу (доходы и расходы)
- Сохранение данных в локальном хранилище UserDefaults

## Технологии

- SwiftUI
- MVVM
- UserDefaults
- Codable
- Combine

## Архитектура

Проект реализован с использованием MVVM:

- Model — содержит модель операции для доходов и расходов

- ViewModel — управляет данными операций, фильтрацией и расчетом баланса; описывает форму редактирования и добавления новой операции

- View — отвечает за UI отображение страниц на экране: страница входа, список операций, окно для редактирования

## Особенности

- Автоматический подсчет баланса
- Локальное сохранение данных без сервера

## Как запустить

- Открыть в Xcode
- Запустить на симуляторе или устройстве
